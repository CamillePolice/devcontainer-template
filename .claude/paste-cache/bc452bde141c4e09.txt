General

Validate roles and groups are arrays

When idTokenClaims is null, accessing properties with optional chaining returns undefined, but the type assertion as string[] | undefined doesn't validate the actual type. If the claim exists but isn't an array, this could cause runtime errors. Add runtime validation to ensure the extracted values are arrays.

Make namespace configurable via secrets

The hardcoded namespace constant should be configurable via environment variable to match the AUTH0_ROLES_NAMESPACE configuration mentioned later in the documentation. This prevents confusion when users need to change the namespace value in multiple places.
